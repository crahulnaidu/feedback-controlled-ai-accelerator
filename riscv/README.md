# RISC-V Integration

This directory contains everything related to the RISC-V processor integration.

## Structure

software/
    Bare-metal programs

drivers/
    Accelerator drivers

integration/
    Hardware integration

tests/
    Functional tests

## Objectives

- Learn the RISC-V ISA
- Understand memory mapping
- Connect the AI accelerator to the processor
- Develop software drivers
- Enable runtime configuration of the accelerator
