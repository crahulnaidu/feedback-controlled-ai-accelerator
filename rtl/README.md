# RTL Design

This directory contains all RTL (Register Transfer Level) hardware modules written in Verilog/SystemVerilog.

## Modules

- alu/
- multiplier/
- mac/
- fifo/
- systolic_array/
- accelerator/

## Future Modules

- dma_controller
- memory_controller
- scheduler
- activation_unit
- quantization_unit
- sparsity_engine
- control_registers

## Goal

Design a runtime-reconfigurable AI accelerator capable of supporting

- Matrix Multiplication
- Convolution
- Transformer Operations
- Quantization
- Sparsity
- Runtime Configuration
